# ADR-0011: Coverage as a polygon enforced at the gateway

- **Status:** Accepted
- **Date:** 2026-09-17
- **Milestone:** M0

## Context

SPEC §1.0 defines coverage as Italy's `admin_level=2` boundary including
islands, plus San Marino, Vatican City and the Campione d'Italia exclave. It
must mask rendering, bound the camera, and constrain search, reverse geocoding
and routing. SPEC §1.5 requires a friendly error for out-of-coverage waypoints.

Italy's shape makes a bounding box useless as the actual test: a bbox
containing Lampedusa (35.49°N) and Vetta d'Italia (47.09°N) also contains
Corsica, half of Tunisia, Slovenia and a good part of Austria.

## Decision

Two tiers, with different jobs:

1. **`ITALY_BBOX`** in `packages/shared` — a cheap pre-filter, and the source
   of the camera's `maxBounds` (bbox + 50 km, SPEC §1.0). Never the
   authoritative answer.
2. **`data/coverage.geojson`** — generated by pipeline step 2 from OSM
   boundaries. The authoritative test, evaluated in the gateway by ray-casting
   point-in-polygon with hole support.

Enforcement lives in the **gateway**, before any upstream call. The client also
checks, but only to give immediate feedback; it is not trusted.

## Degraded mode

Before the pipeline has run there is no polygon. The gateway then falls back to
the bbox and reports `exact: false` from `GET /api/coverage`, and logs a
warning naming the command to fix it. An M0 stack therefore runs end to end
without pretending its coverage is correct.

## Consequences

- Point-in-polygon against a detailed national boundary runs per request. The
  polygon is loaded once at startup; Italy's simplified boundary is small
  enough that this is not a hot spot. If it becomes one, the fix is a spatial
  index, not a coarser polygon.
- The same polygon is served to the client for the render mask, so mask and
  enforcement can never disagree.
- The bbox is unit-tested against nine extreme points of Italian territory
  (Lampedusa, Vetta d'Italia, Capo d'Otranto, Rocca Bernauda, both enclaves,
  Campione d'Italia, Pantelleria, Sardinia), so a careless edit fails CI.
